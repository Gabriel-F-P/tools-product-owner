# Tools Product Owner

Dashboard mockado para acompanhar cards, atrasos e movimentacoes do time.

## Estrutura

- `frontend`: app React + Vite.
- `backend`: API Express mockada.
- `backend/src/integrations/linear`: ponto de entrada para a futura integracao com Linear.

## Rodando localmente

```bash
npm install
npm run dev
```

Frontend: `http://127.0.0.1:5173`

Backend: `http://127.0.0.1:3333`
